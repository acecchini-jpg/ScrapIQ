📖 Passo a passo: como criar o banco no Supabase (primeira vez)
1. Acesse supabase.com e crie uma conta gratuita (pode usar GitHub ou e-mail).
2. Clique em New Project — dê um nome (ex: scrapiq), defina uma senha de banco (guarde-a) e escolha a região South America (São Paulo).
3. Aguarde ~2 min a criação. No menu lateral, abra SQL Editor → New query, cole o SQL abaixo e clique Run:
create table if not exists scrapiq_store (
  store text not null,
  key   text not null,
  doc   jsonb not null,
  primary key (store, key)
);
alter table scrapiq_store enable row level security;
create policy "scrapiq_all" on scrapiq_store
  for all using (true) with check (true);
4. No menu lateral, abra Project Settings → API. Copie:
  • Project URL → cole no campo "URL do Projeto" acima
  • anon public (em Project API keys) → cole no campo "Chave anon" acima
5. Clique Salvar e Testar Conexão. Se aparecer ✓, clique Migrar Dados Locais → Nuvem para subir o que você já tem.
6. Por fim, clique Ativar Nuvem. O badge do cabeçalho mostrará ☁ NUVEM.
⚠ A chave anon é pública por design, mas com a política acima qualquer pessoa com URL+chave pode ler/gravar. Compartilhe apenas com sua equipe.
